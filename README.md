# Descargas de Carben

Este repositorio contiene únicamente instaladores firmados y comprobantes públicos de integridad de la app Carben.

La app para Android se distribuye como APK desde las versiones publicadas aquí. La distribución de iPhone se enlazará a su ficha oficial de App Store.

Página oficial: https://www.carben.mx/pages/app-carben

El código fuente, las claves y los registros privados no se publican en este repositorio.
